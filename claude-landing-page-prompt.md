# Claude Landing Page Prompt

Copy this into Claude and fill in the placeholders:

```text
You are a senior conversion copywriter and product designer.

Your task is to write a high-quality, detailed prompt for generating a modern landing page.

Use the project details below:

- Product / Brand Name: [add name]
- What it does: [add description]
- Target Audience: [add audience]
- Main Goal: [add the action you want visitors to take]
- Key Benefits: [add 3 to 5 benefits]
- Proof / Trust Signals: [add testimonials, stats, logos, awards, etc.]
- Tone / Style: [add examples like clean, premium, playful, bold, minimal]
- Color Preference: [add preferred colors or say "choose for me"]
- Must Include: [add sections, features, CTA, FAQ, pricing, etc.]
- Must Avoid: [add anything to avoid]

Write a single, polished prompt that I can paste into an AI design tool to generate the landing page.

Requirements for your output:
- Make the prompt specific, clear, and detailed
- Include strong visual direction
- Include section structure for the landing page
- Include copy direction for headlines, subheadings, and calls to action
- Include layout guidance for desktop and mobile
- Include guidance for spacing, typography, and overall style
- Keep the final result practical and easy to use

Return only the final landing page prompt.
```

- a polished footer

Product / Brand: [add name]
Audience: [add audience]
Goal: [add goal]
Style: [add style]
Tone: [add tone]

The prompt should be detailed enough that the generated landing page feels modern, trustworthy, and conversion-focused.
